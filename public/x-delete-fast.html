٣. ثبّته في متصفحك

⚠️ في الآيفون Safari فقط — Chrome iOS يحذف البوكماركلت تلقائياً.
١
افتح Safari، وتصفّح هذه الصفحة فيه (ليس Chrome).
٢
اضغط زر "انسخ الكود" أعلاه.
٣
اضغط زر المشاركة 📤 (أسفل الشاشة) → Add Bookmark → اسم: XDel → Save.
٤
افتح Bookmarks 📖 → Edit → اضغط على XDel.
٥
امسح حقل العنوان كاملاً → اضغط مطوّلاً → Paste. يجب أن يبدأ بـ javascript:. Done.
٦
اذهب إلى x.com/your-username → Bookmarks → اضغط XDel → ستظهر لوحة التحكم.
١
اضغط Ctrl+Shift+B لإظهار شريط المفضّلة.
٢
اضغط بزر الفأرة الأيمن على الشريط → Add page.
٣
الاسم: XDel. الـ URL: الصق الكود المنسوخ. احفظ.
٤
افتح x.com/your-username واضغط XDel من الشريط.

٤. ماذا سيحدث؟

  • ستظهر لوحة تحكم عائمة في زاوية الشاشة.
  • اضغط "ابدأ" → ستبدأ الأداة بتمرير الصفحة لجمع IDs التغريدات (بدون أي ضغطات مرئية).
  • ثم تستدعي DeleteTweet API مباشرة لكل تغريدة.
  • ستتجاوز المثبّتة والردود على الآخرين تلقائياً.
  • زر "توقف" يوقفها.
  • ⚠️ إذا رجعت رسالة authorization خطأ، سجّل خروج ودخول مرة ثانية في X.

⚠️ الحذف نهائي — نزّل أرشيف X أولاً.
