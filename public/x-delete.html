🗑️ حذف تغريدات X

أداة محمولة لحذف تغريداتك عبر X API. المفاتيح تُحفظ في جوالك فقط.

١. مفاتيح X API

كيف أحصل عليها؟
  1. افتح developer.x.com وسجّل كمطوّر مجاناً.
  2. Projects → Create Project → Create App.
  3. User authentication settings:
    • Type: Web App or Bot
    • Permissions: Read and write
    • Callback: http://localhost
  4. Keys and tokens → انسخ المفاتيح الأربعة.
  5. ⚠️ لو كان Access Token صلاحيته Read فقط، احذفه وأعد إنشاءه.
