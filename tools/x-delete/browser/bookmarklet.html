🗑️ حذف تغريدات X — بدون API

هذه طريقة بديلة تعمل داخل متصفحك مباشرة (لا تحتاج مفاتيح مطوّر). اسحب الزر الأحمر إلى شريط المفضّلة، ثم افتحه داخل صفحة ملفك الشخصي في X.

⚠️ تحذير: هذه الأداة تعدّل صفحة X في متصفحك فقط. استخدمها على حسابك. الحذف نهائي ولا يمكن التراجع عنه. ننصح بتصدير أرشيف X أولاً.

الخطوة 2 — اسحب هذا الزر إلى شريط المفضّلة

🗑️ حذف تغريداتي

(في Chrome: اضغط Ctrl+Shift+B لإظهار شريط المفضّلة، ثم اسحب الزر إليه.)

الخطوة 3 — استخدمه

  1. افتح https://x.com/your-username (ملفك الشخصي).
  2. اضغط على زر "حذف تغريداتي" من شريط المفضّلة.
  3. ستظهر لوحة تحكم أعلى الصفحة — اضغط "ابدأ".
  4. الأداة ستُمرّر الصفحة تلقائياً وتحذف كل تغريدة بالترتيب.
  5. لإيقافها: اضغط "توقف" من اللوحة نفسها.
